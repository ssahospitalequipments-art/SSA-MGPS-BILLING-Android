# SSA MGPS Billing Android

Modern Android wrapper for:
https://ssa-mgps-billing-v8.sankarmh.workers.dev/

## Build
GitHub Actions automatically builds the APK with:
- Java 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3
- targetSdk 35

After a successful Action run, download the artifact:
`SSA-MGPS-Billing-APK`
